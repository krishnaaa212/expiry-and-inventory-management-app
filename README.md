# expiry-and-inventory-management-app

## Project Description
A mobile application developed using Flutter to simplify inventory management and expiry date monitoring. The system helps users maintain accurate stock records, receive timely expiry alerts, and efficiently organize products through an intuitive interface and barcode-based product identification.

## Key Features
- Real-time inventory tracking
- Product expiry monitoring and reminders
- Barcode scanning for quick product entry
- Stock quantity management
- Secure user authentication
- User-friendly dashboard and inventory reports

## Technology Stack
- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore

## Objectives
- Reduce product wastage caused by expired items
- Improve inventory organization and accessibility
- Provide automated notifications for upcoming expiries
- Enable efficient stock monitoring and management
